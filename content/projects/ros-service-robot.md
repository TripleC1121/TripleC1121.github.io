## 專案簡介
以 NVIDIA Jetson TX2 為運算核心，在 Ubuntu Linux 上用 ROS 整合感測器與深度學習模型，開發可自主移動的服務型機器人。

## 功能
- 無線遠端控制（SSH）
- 2D SLAM 建圖與定位
- 3D 點雲建圖
- 自主導航，含靜態與動態避障
- YOLOv3 物件偵測

## 我的角色
系統整合：感測器設定、ROS 節點串接、導航參數調整與實機測試。

## Overview
A mobile service robot built on NVIDIA Jetson TX2, integrating sensors and a deep-learning model with ROS on Ubuntu Linux.

## Capabilities
- Wireless remote control (SSH)
- 2D SLAM mapping and localization
- 3D point-cloud mapping
- Autonomous navigation with static and dynamic obstacle avoidance
- YOLOv3 object detection

## My role
System integration: sensor setup, ROS node integration, navigation tuning, and on-robot testing.
